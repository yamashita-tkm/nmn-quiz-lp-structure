# NMN クイズ・アンケート型クッションLP構成案

免疫分析研究センターのMeta広告から接続する、以下4パターンの構成検討用静的レポートです。

- 記事D：男性 × クイズ型
- 記事D：男性 × アンケート型
- 記事E：女性 × クイズ型
- 記事E：女性 × アンケート型

`index.html` のみで動作し、GitHub Pagesからそのまま公開できます。

## 内容

- 4案のターゲット・役割・章立て・設問例
- 広告から商品LPまでの共通導線
- 回答フィードバックの簡易インタラクション
- A/Bテスト時のKPIと推奨テスト順
- 健康食品広告としての表現・実装確認項目

## 注意

これは構成検討資料です。記載された品質・価格・研究関連の表現は、実制作時に一次資料、最新の販売条件、薬機法・景品表示法等の確認が必要です。
