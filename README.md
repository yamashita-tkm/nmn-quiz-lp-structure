# NMN クイズ・アンケート型クッションLP構成案

免疫分析研究センターのMeta広告から接続する、以下4パターンの構成検討用静的レポートです。

- 記事D：男性 × クイズ型
- 記事D：男性 × アンケート型
- 記事E：女性 × クイズ型
- 記事E：女性 × アンケート型

`index.html` のみで動作し、GitHub Pagesからそのまま公開できます。4パターンすべてをスマートフォン風モックで回答・遷移テストできます。

## 内容

- 4案のターゲット・役割・章立て・設問例
- 添付画像の上段8バナー→記事E、下段8バナー→記事Dの実画像つき対応図
- 広告から商品LPまでの共通導線
- 回答済み設問を残し、同一ページの下部へ次設問を順次追加するSPインライン回答体験
- 1問回答するごとに、研究姿勢・純度99.9％・1球250mg・国内GMP認証工場等のワンポイントを表示
- A/Bテスト時のKPIと推奨テスト順
- 健康食品広告としての表現・実装確認項目
- バナー→クッションLP→結果・根拠→商品LPの導線概念図
- 同一ターゲット内でクイズ型／アンケート型を切り替える比較導線
- 回答、戻る、結果、商品LP到達までのスマートフォン風操作モック
- インナーエイジングケアを冒頭に置いた、商品距離の近いD2C記事導入
- 短文・会話調で「内側ケア→NMN→選択基準」へつなぐストーリー
- 回答後に続く、生活者の感情・研究機関の姿勢・商品を選ぶ理由をまとめた記事モック
- 参考記事LPを踏まえた、明朝見出し・マーカー・編集メモ・研究パートの誌面調デザイン
- Squad Beyond参考4案のティール帯、太字見出し、短い口語文、研究記事風レイアウトを再構成
- 参考LPの画像構成を踏まえた、商品ヒーロー・研究者・製造工程のオリジナル写真素材

## 注意

これは構成検討資料です。記載された品質・価格・研究関連の表現は、実制作時に一次資料、最新の販売条件、薬機法・景品表示法等の確認が必要です。
